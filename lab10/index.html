우주의 자로 팽창률 재기

약 25분 · 브라우저에서 코드 없이 · Python 선택

DESI 연구진이 공개한 거리비 13개를 연다. 은하 13개의 거리가 아니다. 1,400만 개 넘는 은하와 퀘이사를 분석해 일곱 시대의 거리를 자의 길이(rd)로 나눈 값으로 줄인 것이다. 자의 길이와 우주 모형을 직접 바꿔 보며, 무엇이 자료에서 나오고 무엇이 내가 정한 가정인지 가른다.

1출처부터 확인한다

그래프보다 먼저 읽어야 할 것: 이 자료는 어디서, 무엇으로, 어떻게 만들어졌는가.

자료DESI Collaboration (2025). DESI DR2 Results II: BAO 측정과 우주론 제한. Phys. Rev. D 112, 083515 · doi:10.1103/tr6y-kpc6 · 거리비와 공분산은 CobayaSampler/bao_data 커밋 b7b8a36 · CC BY 4.0
무엇을 쟀나일곱 적색편이 구간(0.295–2.33)에서 은하 분포에 남은 ‘소리 자’를 옆 방향(DM)과 시선 방향(DH), 또는 두 방향을 합친 값(DV)으로 읽고 자의 길이 rd로 나눈 13개 비율. 단위가 없는 비율이다.
이 페이지의 처리mean.txt와 cov.txt는 원본 그대로다. bao.csv는 같은 값에 cov.txt 대각 원소의 제곱근(sigma)을 붙인 것이다. 모형은 평탄한 우주의 교육용 계산이며 연구진의 최적 모형이 아니다.
파일 지문—

2자료와 모형을 직접 맞춰 본다

자의 길이 rd, 오늘의 팽창률 H₀, 물질의 비율 Ωm을 바꾼다. 점은 관측, 곡선은 모형이다. χ²는 13×13 공분산 전체로 계산한다.

① 13개 거리비(점)와 오차 막대(공분산 대각 원소의 제곱근), 현재 조건의 모형 곡선. 막대의 색: 청록 DM/rd, 주황 DH/rd, 검정 DV/rd.

② DH/rd 여섯 점을 현재 rd로 H(z)로 바꾼 값(점)과 현재 H₀·Ωm의 곡선 H₀·E(z). 오차 막대는 rd를 고정하고 대각 원소만 옮긴 근사다.

3해 볼 일

  1. 줄부터 확인한다. 아래 표에서 z=0.510의 두 줄(DM/rd 13.588, DH/rd 21.863)을 찾는다. 각각 그림 ①의 어느 점인가?
  2. 비율을 팽창률로 바꾼다. DH는 빛의 속도를 H로 나눈 값이다. H(z) = 299,792.458 ÷ (DH/rd × rd). rd=147을 넣으면 얼마인가? (표의 ‘H(0.51)’ 칸과 손 계산을 비교한다.)
  3. 자의 길이만 바꾼다. rd를 140으로 옮겨 본다. 같은 비율에서 H(z)는 어떻게 되는가? 관측값 자체는 바뀌었는가?
  4. 같은 곱, 다른 조건. H₀=71.4, rd=140으로 놓는다(바로 가기). 두 수의 곱은 9,996으로 처음과 같다. 곡선과 χ²는 어떻게 되는가? Ωm만 0.35로 바꾸면?
  5. 기록한다. 표에서 읽은 값, 내가 정한 조건, 바뀐 결과, 남은 가정을 나누어 6절의 연구 노트에 적는다. 파일 지문도 함께 남긴다.

4예상 결과와 비교한다

책 10장 오른쪽 쪽의 숫자다. 위 조작판의 현재 조건으로 계산한 값을 책의 처음 조건 값과 견준다. 조건을 바꿨다면 달라지는 것이 정상이다. 무엇이 달라졌는지가 이 실습의 핵심이다.

자를 바꾸면 팽창률은 바뀌지만 어긋남은 그대로다

비교 조건(처음): rd=147, H₀=68, Ωm=0.30. 아래 세 줄은 현재 조작과 상관없이 책의 다른 조건(rd=140 / H₀=71.4·rd=140 / Ωm=0.35)으로 이 페이지의 계산이 책의 숫자를 내는지 확인한다.

  • 관측된 비율 21.863은 그대로이고, 바뀐 것은 내가 정한 자의 길이다. 단위가 붙은 팽창률을 말하려면 rd를 따로 알아야 한다. 93.3은 적색편이 0.51 시대의 팽창률이지 오늘의 허블 상수가 아니다.
  • H₀와 rd를 같은 곱으로 바꾸면 예측이 하나도 달라지지 않는다. BAO만으로는 두 값을 따로 정할 수 없다는 뜻이다. 반면 Ωm은 시대별 모양을 바꿔 χ²가 크게 변한다. χ²는 이 계산 조건에서의 어긋남 요약일 뿐, 모형이 참일 확률이 아니다.

결과가 다르다면

  • H(z)가 조금 다르면 빛의 속도를 km/s 단위(299,792.458)로 썼는지, DM 줄과 바꿔 읽지 않았는지 본다.
  • χ²가 다르면 13×13 공분산 전체를 썼는지, 파일 지문이 9ac154ab…(mean)와 252a1432…(cov)로 시작하는지 확인한다.

5같은 계산을 코드로

표준 라이브러리만 쓰므로 Python 3만 있으면 된다.

python3 analysis.py                              # 처음 조건 H0=68, rd=147, Ωm=0.30
python3 analysis.py --check                      # 책의 예상 결과와 비교
python3 analysis.py --h0 71.4 --rd 140           # 같은 곱, 다른 조건
python3 analysis.py --om 0.35                    # Ωm만 바꾸기
python3 analysis.py --scan-om                    # Ωm을 0.25–0.35에서 훑기
analysis.py같은 계산 · 표준 라이브러리 notebook.ipynb그림과 함께 따라 하기 expected.json책의 예상 결과 data/bao.csv13개 거리비 · sigma data/mean.txt원본 값 data/cov.txt13×13 공분산 원본 data/provenance.json출처·처리·감사문

6연구 노트

질문은 좁게, 선택과 결과는 따로. 다른 사람이 똑같이 다시 할 수 있게 적는다.

다음 걸음

Ωm을 0.25에서 0.35까지 조금씩 바꾸며 χ²가 가장 작아지는 곳을 찾아 기록해 보자(--scan-om). 그 값을 연구진의 결과와 비교하기 전에, 내 계산에서 빠진 것(공간의 휘어짐, 변하는 암흑에너지, 우주배경복사와 초신성)을 먼저 적는다.
