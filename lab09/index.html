341개 목록에서 표본을 직접 고르기

약 20분 · 브라우저에서 코드 없이 · Python 선택

코체브스키 연구진이 공개한 341개 목록을 연다. 한 줄이 대상 하나이고, 적색편이와 그 측정 방법(분광 1, 광도 0), 4.44마이크로미터 밝기(mag444, 작을수록 밝다)가 들어 있다. 밝기 조건 하나를 거는 결정이 표본을 어떻게 바꾸는지 직접 눈금을 돌려 확인한다.

1출처부터 확인한다

그래프보다 먼저 읽어야 할 것: 이 자료는 어디서, 무엇으로, 어떻게 만들어졌는가.

자료Kocevski, D. D. 외 (2025). 제임스웹으로 찾은 z>4 작고 붉은 활동성 은하핵 후보 표(Table 3). ApJ 986, 126 · doi:10.3847/1538-4357/adbc7d · 저자 저장소 dalekocevski/Kocevski24 (커밋 b47c187)
무엇인가여러 제임스웹 조사(CEERS, PRIMER-UDS, NGDEEP 등)에서 모은 341개 목록. 무작위 표본이 아니고, 조사마다 면적과 깊이가 다르다.
이 페이지의 처리원본 Table3.dat를 열 이름이 있는 CSV로 옮겼을 뿐 행을 거르거나 값을 바꾸지 않았다. 학술지 PDF는 zflag를 1=광도, 2=분광으로 적어 이 저장소판(0=광도, 1=분광)과 다르다. 실습의 숫자는 이 고정된 저장소판에 대한 것이다.
파일 지문—

2목록을 직접 거른다

mag444 한계를 움직여 본다. 조건은 ‘<’이다. 한계와 같은 밝기는 남기지 않는다.

3해 볼 일

  1. 분모부터 확인한다. 전체 341개, 분광 39개인지 센다. 이후 모든 비율의 분모다. (‘조건 없음’을 누른다.)
  2. 밝기 조건을 건다. mag444 < 26.5만 남긴다. 몇 개가 남고 그중 분광은 몇 개인가? ‘같다’는 포함하지 않는다.
  3. 조건을 바꿔 본다. 26과 27로 바꿔 대상 수를 표로 적는다.
  4. 분포를 비교한다. 조건을 건 표본(색 막대)과 전체(회색 막대)를 나란히 본다. 어느 구간이 많이 빠지는가? 아래 표의 ‘남은 비율’을 읽는다.
  5. 기록을 남긴다. 조건, 남은 수, 분모, 파일의 지문(SHA-256)을 6절의 연구 노트에 적는다.

4예상 결과와 비교한다

책 9장 오른쪽 쪽의 숫자다. 조건을 바꿨다면 값이 달라지는 것이 정상이다. 무엇이 달라졌는지가 이 실습의 핵심이다.

밝은 것만 남기면 표본이 가까운 쪽으로 쏠린다

비교 조건: mag444 < 26.5, 대상 전체 341개. 책의 값은 이 조건에서 230개(분광 33개)가 남고, 26이면 175개(27개), 27이면 286개(37개)라는 것이다. 적색편이 중앙값은 전체 6.13, 통과 5.80, 빠진 111개 7.00이고 5–6 구간은 76%, 9–10 구간은 23%만 남는다.

이렇게 읽는다

  • 밝기 조건은 먼 대상을 더 많이 덜어 낸다. 같은 밝기의 천체라도 멀수록 어둡게 보이기 때문이다. 그래서 ‘밝은 표본에서 적색편이 5–6이 가장 많다’를 ‘그 시대에 작은 붉은 점이 가장 많았다’로 읽으면 안 된다. 표본을 고르는 조건이 분포의 모양을 함께 만든다.
  • 33/230을 ‘블랙홀이 확인된 비율’로 쓸 수 없다. 이 열은 적색편이를 잰 방법일 뿐이다. 이 실습으로 질량을 계산하거나 산란 해석을 검증할 수도 없다.

결과가 다르다면

  • 대상 수가 다르면 조건을 ‘≤’로 걸지 않았는지, 숫자 열을 문자로 읽지 않았는지 본다.
  • 그래도 다르면 내려받은 원본 Table3.dat의 SHA-256이 27372eee…711de인지 확인한다. 이 페이지의 catalog.csv는 그 변환본이라 지문이 다르다(4b7f690c).

5같은 계산을 코드로

표준 라이브러리만 쓰므로 Python 3만 있으면 된다.

python3 analysis.py                          # 기본: mag444 < 26.5
python3 analysis.py --check                  # 책의 예상 결과와 비교
python3 analysis.py --mag-limit 27           # 조건을 바꿔 보기
python3 analysis.py --method spec            # 분광 적색편이 39개만 대상으로
