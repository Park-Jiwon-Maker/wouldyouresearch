펄서 후보 분류기 시험하기

약 30분 · 브라우저에서 코드 없이 · Python 선택

파크스 망원경의 실제 펄서 후보 17,898개로 분류기를 만들고 시험한다. 목표는 높은 점수가 아니다. 그 점수가 무엇을 뜻하는지 정직하게 말할 수 있게 되는 것이다. 이 페이지에는 학습이 끝난 점수가 들어 있고, 당신이 고르는 것은 ‘어디서 자를까’, 곧 문턱이다.

1출처부터 확인한다

그래프보다 먼저 읽어야 할 것: 이 자료는 어디서, 무엇으로, 어떻게 만들어졌는가.

자료HTRU2. Lyon, R. J. 외 HTRU 공동연구진, 파크스 전파망원경 관측. UCI doi:10.24432/C5DK6R · CC BY 4.0
무엇인가후보 17,898행. 한 행은 접은 펄스 모양과 분산 측정 곡선에서 뽑은 여덟 숫자이고, 마지막 열은 사람이 붙인 정답이다(1=펄서). 원시 시계열이 아니다.
이 페이지의 처리표는 그대로다. 파생 파일은 둘: scores.csv(행마다 묶음·정답·학습된 점수)와 model.json(평균·표준편차·가중치). 묶음은 펄서와 아닌 것을 따로 섞어 60/20/20, 시작값 20261023. 평균과 표준편차는 학습 묶음으로만 구했다.
알아 둘 것행은 서로 다른 천체가 아니라 후보다. 같은 펄서가 여러 행에 나올 수 있고, 천체·시각·위치 식별자가 없어 천체 단위로 나눌 수 없다. 점수는 확률이 아니다.
파일 지문—

표를 연다 · 첫 5행

2문턱을 직접 움직여 본다

점수가 문턱 이상이면 ‘펄서 후보로 남긴다’. 문턱을 올리면 잘못 남기는 것이 줄지만 진짜 펄서를 더 놓친다. 색 띠가 남기는 쪽이다.

펄서펄서 아님색 띠 = 남기는 쪽

놓친 펄서

점수가 낮은 순 상위 12행. 여덟 숫자는 원본 열 순서(1–8)다.

3해 볼 일

  1. 표를 연다. 한 행이 후보 하나라는 것, 마지막 열이 사람이 붙인 정답이라는 것을 확인한다. 펄서는 몇 행인가? (위 표와 지문 아래의 요약)
  2. 나눈다. 묶음 행 수가 10,738 / 3,578 / 3,582인지 본다. 평균과 표준편차를 전체가 아니라 학습 묶음으로만 구했다는 점이 왜 중요한지 한 줄로 적는다.
  3. 기준선을 잰다. 시험 묶음을 고르고 아래 표의 ‘모두 아님’ 정확도와 재현율을 적어 둔다. 분류기의 정확도와 얼마나 차이 나는가?
  4. 문턱을 고른다. 검증 묶음에서 슬라이더를 움직여, 펄서를 90% 이상 남기는 가장 높은 문턱을 찾는다. ‘검증에서 고른 문턱’ 단추와 같은 값인가? 고른 이유를 한 줄로 적는다.
  5. 시험 묶음을 한 번 연다. 고른 문턱 그대로 시험을 눌러 남김·놓침·잘못 남김과 재현율·정밀도를 기록한다. 그 뒤 문턱을 바꿔 보는 것은 모두 ‘사후 탐색’이다. 화면에도 표시된다.

4예상 결과와 비교한다

책 7장 오른쪽 쪽의 숫자다. ‘시험, 현재 문턱’ 항목은 슬라이더를 따라 바뀐다. 문턱을 바꿨다면 다른 것이 정상이다. 무엇이 달라졌는지가 이 실습의 핵심이다.

시험 묶음의 펄서 329개 중 287개를 남겼고, 남긴 345개 중 58개는 펄서가 아니었다

비교 조건: 문턱 0.16(검증 재현율 90% 기준으로 고른 값), 시험 묶음 3,582행. 위쪽 세 행은 슬라이더와 무관하게 ‘고르는 규칙’의 결과이고, 아래쪽은 현재 문턱을 시험 묶음에 적용한 결과다.

읽기. 정확도 97.2%는 아무것도 하지 않는 90.8%보다 6.4%포인트 높을 뿐이다. 이 분류기가 한 일은 ‘펄서 42개를 놓치는 대신, 확인할 후보를 3,582개에서 345개로 줄였다’로 쓰는 편이 정직하다. 재현율은 검증의 90.8%에서 시험의 87.2%로 낮아졌다. 문턱을 검증 묶음에 맞춰 골랐고 펄서가 300여 개뿐이라 몇 개 차이로도 비율이 흔들린다. 같은 펄서가 여러 행에 나올 수 있으므로 이 숫자는 새 펄서를 찾는 능력이 아니라 이 표 안에서의 성적이다.

결과가 다르다면

  • 행 수가 10,738 / 3,578 / 3,582가 아니면 나누는 방식과 시작값을 확인한다. 전체 자료로 표준화하지 않았는지도 본다.
  • 문턱이 0.16과 다르면 검증이 아니라 시험 묶음으로 문턱을 고르지 않았는지 확인한다.
  • Python 결과가 화면과 다르면 파일 지문(SHA256)부터 비교한다.

5같은 계산을 코드로

표준 라이브러리만 쓰므로 Python 3만 있으면 된다. 처음부터 다시 학습해 보는 --retrain만 NumPy가 필요하다.

python3 analysis.py                         # 검증에서 문턱을 고르고 시험 결과를 본다
python3 analysis.py --check                 # 책의 예상 결과와 비교
python3 analysis.py --threshold 0.5         # 다른 문턱(사후 탐색)
python3 analysis.py --target-recall 0.95    # 검증 재현율 목표 바꾸기
python3 analysis.py --retrain               # 분할·학습부터 다시(NumPy)
