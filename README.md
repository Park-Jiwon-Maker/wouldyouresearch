# 우주 리서치 · 실습 (Would you research?)

《우주 리서치 — 지금 천문학자들이 묻는 열 개의 질문, 그리고 당신의 차례》(박지원 · 김용기)의 동반 실습 사이트입니다.
책의 장마다 실제 연구 자료로 하는 실습이 하나씩 있고, 책의 QR 코드가 각 실습 페이지로 연결됩니다.

| 실습 | 장 | 주제 |
|---|---|---|
| [lab00](lab00/) | 서문 | 연구 동향을 다시 계산하기 (OpenAlex) |
| [lab01](lab01/) | 1장 태양 폭풍 | 경보선을 어디에 그을까 (NOAA 플레어 예보) |
| [lab02](lab02/) | 2장 돌의 기억 | 달의 두 얼굴, 지각 두께로 비교하기 (GRAIL) |
| [lab03](lab03/) | 3장 소행성 방위 | 33분에서 β까지 (DART) |
| [lab04](lab04/) | 4장 화성의 돌 | 표범 무늬의 원소 세기 (퍼서비어런스 PIXL) |
| [lab05](lab05/) | 5장 얼음 아래 바다 | 인산염의 지문 찾기 (실험실 질량 스펙트럼) |
| [lab06](lab06/) | 6장 다른 행성의 하늘 | 이산화탄소의 봉우리 재기 (제임스웹 WASP-39 b) |
| [lab07](lab07/) | 7장 하늘의 자료 | 펄서 후보 분류기 시험하기 (HTRU2) |
| [lab08](lab08/) | 8장 시공간의 떨림 | 두 관측소의 떨림 겹쳐 보기 (GWOSC) |
| [lab09](lab09/) | 9장 작은 붉은 점 | 341개 목록에서 표본 고르기 (제임스웹) |
| [lab10](lab10/) | 10장 우주의 자 | 우주의 자로 팽창률 재기 (DESI DR2) |

각 폴더에는 브라우저 실습(`index.html`), 같은 계산을 하는 Python 코드(`analysis.py`, `--check`로 책의 예상 결과와 비교), 노트북(`notebook.ipynb`), 자료와 출처(`data/provenance.json`)가 들어 있습니다.
설치 없이 브라우저에서 시작할 수 있고, Python 코드는 표준 라이브러리만 씁니다.

자료의 이용 조건은 폴더마다 `data/provenance.json`에 적은 원래 출처(NASA, ESA, NOAA, GWOSC, DESI, Zenodo 등)를 따릅니다.
